# Dynamic Lock for Obsidian

[English](../README.md)

속성·폴더·노트가 작성된 기간에 따라 Markdown 노트를 읽기 또는 편집 모드로 열어요. **열린 뒤 자유롭게 전환하거나, 선택한 노트의 읽기 모드를 유지할 수 있어요.**

참고용 노트는 바로 읽고, 작업 중인 초안은 바로 편집하세요. 노트를 열 때마다 모드를 바꾸는 수고를 줄여줘요.

## 이럴 때 유용해요

- `References/`의 참고 자료는 읽기 모드로, `Drafts/`의 초안은 편집 모드로 열고 싶을 때.
- `status: done` 속성이 있는 완성된 노트를 읽기 모드로 열고 싶을 때.
- 생성일로부터 30일이 지난 일기를 읽기 모드로 열고 싶을 때.

기본적으로 수정이 필요하면 언제든 편집 모드로 전환할 수 있어요. 읽기 속성·폴더 규칙에서 **수정 불가**를 켜면 편집 모드 전환을 미리 막고 알림을 보여줘요. Obsidian 화면에 적용되는 동작이며, 파일을 읽기 전용으로 만들거나 외부 도구의 수정을 막지는 않아요.

## 빠르게 시작하기

1. **설정 → Dynamic Lock**에서 **폴더 규칙**을 찾아요.
2. **폴더 규칙 추가**를 선택하고, 참고 자료 폴더와 **읽기** 모드를 지정해요.
3. 전역 모드는 **자동**으로 두고, 해당 폴더의 노트를 열어봐요.
4. 수정하고 싶으면 Obsidian의 기본 모드 전환 기능으로 편집 모드로 바꾸세요. 다른 탭에 다녀와도 직접 선택한 모드는 유지돼요.

처음에는 규칙이 없고 **기본 모드**가 **현재 모드 유지**로 설정돼 있어요. 규칙을 추가하거나 기본 모드를 선택하면 노트를 여는 방식을 바꿀 수 있어요.

## 규칙과 전역 모드

폴더·속성 규칙은 읽기와 편집 중 원하는 모드를 지정할 수 있어요. 시간 기반 규칙은 생성일 또는 마지막 수정일로부터 지정한 기간이 지난 노트를 읽기 모드로 열어요.

상태 표시줄을 선택하면 전역 모드가 순서대로 바뀌어요. 명령어 팔레트에서도 바꿀 수 있어요.

| 상태 표시줄 | 노트를 열 때의 동작 |
| :--- | :--- |
| **자동** | 규칙을 적용하고, 일치하는 규칙이 없으면 **기본 모드**를 사용해요. |
| **잠금** | 규칙과 관계없이 읽기 모드로 열어요. 열린 뒤에는 편집 모드로 전환할 수 있어요. |
| **편집** | 규칙을 먼저 적용하고, 일치하는 규칙이 없으면 편집 모드로 열어요. |

여러 규칙이 해당되면 아래 순서에서 가장 먼저 일치하는 조건이 모드를 정해요.

1. 전역 **잠금** 모드 → 읽기.
2. **속성 규칙** → 설정 목록에서 가장 먼저 일치하는 속성 규칙.
3. **폴더 규칙** → 가장 구체적인 폴더 규칙. 하위 폴더에도 적용돼요.
4. **시간 기반 잠금** → 지정한 기간이 지났으면 읽기.
5. 전역 **편집** 모드 → 편집.
6. **기본 모드** → 현재 모드 유지, 읽기 또는 편집.

### 선택한 노트 수정 잠그기

읽기 속성·폴더 규칙에는 **수정 불가** 토글이 있어요. 새 규칙은 기본으로 꺼져 있어요. 위 우선순위로 선택된 규칙의 옵션만 적용하므로, 하위 폴더나 속성 규칙으로 예외를 만들 수 있어요. 전역 **잠금** 모드가 우선 적용되는 경우에는 직접 모드를 전환할 수 있어요.

직접 편집하려면 토글을 끄세요. 규칙을 편집 모드로 바꾸면 토글이 숨겨지고 꺼짐으로 초기화돼요. 시간 기반 규칙과 기본 모드에는 수정 잠금이 적용되지 않아요. 기존 **읽기 모드 유지** 설정은 호환성을 위해 **수정 불가**로 적용돼요.

### 노트를 연 뒤에는 어떻게 되나요?

선택된 규칙에 **수정 불가**가 켜져 있지 않으면, 직접 선택한 읽기·편집 모드는 탭을 이동하거나 노트 속성을 바꿔도 유지돼요. 직접 모드를 바꾸지 않았다면, 적용되는 규칙이 달라질 때 화면 모드도 바뀔 수 있어요.

같은 탭에서 다른 파일을 열거나, 노트를 다시 열거나, 플러그인을 다시 로드하면 설정된 모드를 다시 적용해요. 플러그인 설정을 변경하거나 전역 모드를 선택하면 열려 있는 모든 Markdown 노트에 설정을 다시 적용해요.

상태 표시줄은 **전역 모드**를 보여줘요. 노트 탭에는 적용 중인 규칙이 편집을 막을 때만 잠긴 자물쇠가 표시돼요. 편집할 수 있는 노트에는 탭 아이콘이 없어요.

## 설치

Obsidian **1.4.10** 이상이 필요해요.

1. **설정 → 커뮤니티 플러그인**을 열고, 필요한 경우 **제한 모드**를 꺼주세요.
2. **찾아보기**에서 `Dynamic Lock`을 검색해요.
3. **설치**한 뒤 **활성화**해요.

### 수동 설치

1. [최신 릴리스](https://github.com/Ryeom/obsidian-dynamic-lock/releases/latest)에서 `main.js`, `manifest.json`, `styles.css`를 다운로드해요.
2. `<vault>/.obsidian/plugins/dynamic-lock/` 폴더를 만들고 세 파일을 복사해요.
3. Obsidian을 다시 로드하고 **설정 → 커뮤니티 플러그인**에서 **Dynamic Lock**을 활성화해요.

## 명령어

**설정 → 단축키**에서 각 명령어에 단축키를 지정할 수 있어요.

| 명령어 | 동작 |
| :--- | :--- |
| `전역 모드 전환` | 자동 → 잠금 → 편집 순서로 전환해요. |
| `전역 모드를 자동으로 설정` | 규칙과 기본 모드를 적용해요. |
| `전역 잠금 설정 (읽기)` | 열린 노트에 읽기 모드를 적용하고, 새로 여는 노트도 읽기 모드로 열어요. |
| `전역 모드를 편집으로 설정` | 규칙을 적용하고, 해당하지 않는 노트는 편집 모드로 열어요. |

명령어 사용 후에도 선택된 규칙에 **수정 불가**가 켜져 있지 않으면 각 노트의 모드를 자유롭게 전환할 수 있어요.

## 다국어 지원

설정 화면·명령어·상태 표시줄·알림은 모두 Obsidian의 언어 설정을 따라가요. 한국어와 영어를 지원하며, 언어 조회 API가 없는 Obsidian 1.8.7 이전 버전에서는 영어로 표시해요.

다른 언어를 추가하려면 `src/i18n/locales/en.json`을 같은 폴더에 `<언어 코드>.json`으로 복사한 뒤, 키는 그대로 두고 값만 번역하세요. 파일 이름은 `ja.json`, `pt-br.json`처럼 Obsidian 언어 코드에 맞춰 소문자로 작성하세요. `npm run build`를 실행하면 JSON 파일을 자동으로 찾아 `main.js`에 포함하므로 언어 목록이나 import를 수정할 필요가 없어요. 빌드 결과를 설치한 뒤 플러그인을 다시 로드하면 적용돼요. 설치할 때 번역 파일을 따로 복사할 필요는 없어요.

지역별 번역이 없으면 기본 언어, 그다음 영어를 사용해요. 누락되거나 비어 있는 번역, 문자열이 아닌 값도 같은 순서로 대체해요. 저장된 속성 값·규칙·모드·명령어 ID는 바뀌지 않아요. 기존 단축키도 그대로 유지돼요. Obsidian 언어를 바꾼 뒤 명령어 이름까지 반영하려면 플러그인을 다시 로드하세요.
